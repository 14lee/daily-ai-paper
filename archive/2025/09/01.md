| R-4B: Incentivizing General-Purpose Auto-Thinking Capability in MLLMs
  via Bi-Mode Annealing and Reinforce Learning (Read more on [arXiv](https://arxiv.org/abs/2508.21113) or [HuggingFace](https://huggingface.co/papers/2508.21113))| Han Hu, Shiming Xiang, Bolin Ni, Qi Yang, Jie Jiang | The paper introduces R-4B, a multimodal large language model that adaptively activates step-by-step reasoning based on query complexity through bi-mode annealing and reinforcement learning. The research objective is to create an efficient "auto-thinking" MLLM that autonomously decides when to engage in complex reasoning versus providing a direct answer, mitigating the computational overhead of constant thinking. The methodology is a two-stage process: first, "bi-mode annealing" trains a base model on a mixed dataset of thinking and non-thinking examples to establish dual capabilities, followed by "Bi-mode Policy Optimization (BPO)," a reinforcement learning framework that incentivizes optimal mode selection by forcing the policy to generate responses in both modes for each query. R-4B achieves state-of-the-art results across 25 benchmarks, attaining a score of 68.1% on MMMU and demonstrating that the BPO stage improves average performance on key reasoning benchmarks from 43.7% to 58.1% over the base model. For AI practitioners, this framework provides a practical method to develop more computationally efficient and context-aware MLLMs that allocate expensive reasoning resources only when required, making them more viable for production environments with diverse workloads. |

The primary objective is to address the inadequacy of existing snippet-based benchmarks by creating a reproducible framework that assesses LLM performance within the full context of real-world software repositories containing documented CVEs. Its methodology relies on a Dockerized, containerized evaluation pipeline that uses expert-defined, CWE-calibrated static analysis rules (combining CodeQL and Joern) to deterministically validate model-generated patches for security, build integration, and stability across repeated runs. The evaluation finds that while Claude-3.7-Sonnet achieves the best overall performance with a score of 63.01, the open-source model Qwen3-235B-A22B-Instruct attains the highest security-specific score (48.03), and concise "fast-thinking" decoding strategies consistently outperform complex reasoning for security patching. The principal implication for AI practitioners is that even flagship models prioritize functional correctness over security, generating a high proportion of insecure but buildable code, which underscores the critical need for repository-level security validation before deploying AI-generated code. |

| Think in Games: Learning to Reason in Games via Reinforcement Learning

The primary objective is to enable LLMs to convert static, text-based knowledge into dynamic, procedural understanding for effective decision-making in interactive settings like MOBA games. The core methodology reformulates RL-based decision-making as a language modeling task, using Group Relative Policy Optimization (GRPO) to iteratively refine language-guided policies based on environmental feedback and a rule-based binary reward function. The main objective is to develop a computationally efficient method for dynamically selecting pre-training data based on a language model's evolving learning preferences to improve its final performance. The key methodology involves Group Influence, an extension of classical influence functions to entire data domains, which quantifies their impact on model learning. This metric is optimized via two approaches: TiKMiX-D for direct multi-objective optimization of the data mixture, and TiKMiX-M, which uses a LightGBM regression model to predict the influence of complex mixtures and find a superior ratio. The TiKMiX-M method achieved an average performance gain of 2% across nine downstream benchmarks for a 1B parameter model, while the more efficient TiKMiX-D variant surpassed the state-of-the-art REGMIX method while using only 20% of its computational resources. The principal implication for AI practitioners is that Group Influence provides a computationally feasible and principled metric to dynamically adjust data diets during large-scale pre-training, enabling more efficient resource utilization and the development of higher-performing models without relying on expensive proxy model training. |

The objective is to address the lack of standardized benchmarks by creating a unified framework that aggregates existing datasets, introduces two new synthetic datasets (PARADE for bias and CoRe-Bench for reasoning), and enables equitable comparison across models. | HERMES: Human-to-Robot Embodied Learning from Multi-Source Motion Data

The main objective is to create a system that translates multi-source human motion data into deployable robot policies capable of long-horizon, mobile manipulation in unstructured, real-world environments. The methodology involves training a state-based expert policy using reinforcement learning guided by a one-shot human motion trajectory and a generalizable reward function, followed by distilling this expert into a vision-based student policy using DAgger and a tailored depth image augmentation pipeline; this is integrated with a ViNT navigation model augmented by a closed-loop Perspective-n-Point (PnP) algorithm for precise localization. In real-world experiments, the HERMES framework achieved an average success rate of 67.8% across six dexterous manipulation tasks, a +54.5% performance increase over a baseline using non-augmented depth images for sim2real transfer. The principal implication for AI practitioners is that a single human demonstration, when coupled with a generalized RL reward structure and a robust distillation framework, can effectively produce complex, physically-realizable dexterous manipulation policies, significantly lowering the barrier for data collection and reward engineering. |
